# 회화 — 힌디어 특이점

공통 원칙은 **https://talkverse.uk/talkverse/dialogue-rules/** (2026-11-02 확정)를 따른다. 절벽 구간 기준표는 https://talkverse.uk/cliff/18/ 이다.
이 문서에는 힌디어만의 규칙만 적는다. 표기표와 길이 기준은 2026-11-02 초안이고, 검사 스크립트를 만들 때 함께 확정한다.

## 1. 기본 변이

- 표준 힌디어(델리 구어, `hi-IN`), 데바나가리로 쓴다. 로마자는 보조로만 쓴다.
- 일상 구어에 흔한 페르시아·아랍계 어휘(ज़रूर, शुक्रिया 등)는 그대로 쓴다. 누크타(ज़·फ़·क़)도 표기한다.
- 우르두(나스탈리크 문자)는 다른 변이다. 만들게 되면 별도 파일로 둔다.

## 2. 성별판

힌디어는 **화자 성별에 따라 동사·형용사 모양이 바뀐다.** 여기에 들어가는 형태는 다음과 같다.
- 진행형 `रहा/रही`, 습관형 `करता/करती`, 미래형 `-गा/-गी`, 과거 분사 `गया/गई`
- 주어 `तुम`·`आप`에 맞추는 미래 의문형(`चलोगे/चलोगी`)
- 형용사는 명사의 성을 따른다. 예: `अच्छा/अच्छी`. 이 경우는 화자가 아니라 명사에 맞추므로 성별판으로 바꾸지 않는다.

성별판 규칙은 다음과 같다.
- 판은 학습자 A(남/여) × 상대 B(남/여) 네 가지다. 기본판은 A 남 · B 여다(지금 초안과 같다).
- 다른 판은 **규칙 치환**으로 만든다. 치환 대상은 위 어미와, 그 문장의 주어가 A인지 B인지다.
- 한글 독음(`rd`)도 같이 바꾼다. 예: 라하 ↔ 라히, 둥가 ↔ 둥기.
- 각 턴의 `note`에 성별 일치가 있으면 "(남성)/(여성)"을 붙인다.

## 3. 한글 독음 표기표 (초안)

| 데바나가리 | 한글 | 예 |
|---|---|---|
| 모음 अ/आ · इ/ई · उ/ऊ | 아 · 이 · 우 (장단 구분 안 함) | आज 아즈 |
| ए/ऐ · ओ/औ | 에 · 오/아우 | और 아우르 |
| 비음 ं ँ | 받침 ㅇ | हूँ 훙, हैं 헹 |
| 단어 끝 묵음 a | 적지 않음 | नाम 남 |
| क/ख/क़ · ग/घ | ㅋ · ㄱ | कहाँ 카항 |
| च/छ · ज/झ/ज़ | ㅊ · ㅈ | चाय 차이 |
| ट/ठ/त/थ · ड/ढ/द/ध | ㅌ · ㄷ | तक 타크 |
| ड़/ढ़ | ㄹ | बढ़िया 바리야 (지금 초안의 "바디야"는 고칠 것) |
| प/फ/फ़ · ब/भ | ㅍ · ㅂ | पैदल 페달 |
| य · व | 야행 · 와행(자음 뒤는 ㅂ) | वाह 와 |
| श/ष/स · ह | 샤행/ㅅ · ㅎ | शहर 샤하르 |
| र · ल | ㄹ · ㄹ(모음 사이 ㄹㄹ) | दिल्ली 딜리 |
| है · हैं | 헤 · 헹 | |

- 유기음(ख·घ·थ 등)은 구분하지 않는다. 보조 로마자에서만 구분한다.
- 검사 스크립트는 `rd`가 비었는지, 한글 아닌 글자가 섞였는지를 먼저 보고, 표기표와 어긋나는지는 경고로만 낸다.

## 5. 지금 데이터와 원칙의 차이 (할 일)

- 지금 데이터는 `assets/data/dialogues/L1.json`의 5편 × 8턴이고, 원칙에 맞춰 손볼 데가 남아 있다.
  - 원칙은 L이 아니라 R 구간을 쓴다. R1 어휘 목록이 아직 없어서 다시 태그하지 못했다.
  - 원칙이 요구하는 반전(`twist`)·`flags`·`purpose[]`·`domain[]` 태그가 없다.
  - 모든 턴이 `draft`다.
- 둘 사이 말투는 이미 친구 사이 `तुम`이고, 낯선 사람에게는 `आप`/`कीजिए`를 써서 원칙 §5에 맞는다. 다만 가까워지는 전환 장면은 아직 없다.
- 템플릿에서 남은 흔적이 있다. 대상어 칸 이름이 `es`이고, `_meta.json`은 "콘텐츠 대기 · 0턴"으로 낡아 있다. 변환기가 공통 모양으로 바꿀 때 함께 정리한다.
- 원본은 `_update_kit/content/hi.py`이고 `build_content.py`로 만든다. 회화를 고칠 때는 원본을 고친다.
